# Resqlink-emergency-response
ResQLink is a planned multilingual emergency assistance app. It uses Gemini to understand emergency messages, GPS to locate users, and geospatial analysis to find nearby facilities and assess available hazard information. It aims to provide clear guidance and keep essential resources available offline.


PROJECT PHASE:

1 Project structure 
2 FastAPI backend and REST APIs —  the basic API and message endpoint.
3 Database and CRUD — store and manage emergency and facility information.
4 Gemini integration — connect your API key safely and test an AI response.
5 Emergency NLP — identify emergency type and key details from the message.
6 GPS and location handling — receive the user’s coordinates.
7 Geospatial analysis — distances, affected areas, and nearby facilities.
8 Live information services — weather, traffic, alerts, maps, and facilities.
9 Offline and weak-network support — use cached information when needed.
10 Multilingual processing — handle messages and guidance in different languages.
11 Mobile application — build the app and connect it to the backend.
12 Integration and testing — test the complete system and prepare project documentation and viva material.
